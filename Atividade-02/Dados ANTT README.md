# Atividade 02 – Análise de Dados ANTT 🚛

## 📌 Sobre a atividade

Nesta atividade foi realizada uma análise da base de dados da **ANTT**, contendo informações sobre empresas e operadores autorizados a realizar o transporte multimodal.

A planilha apresenta dados como país de origem, razão social, CNPJ, cidade, estado (UF), CEP, adesão ao Decreto 1563/95 e período de vigência.

## 🎯 Objetivo

O objetivo da atividade foi utilizar ferramentas de análise de dados para organizar e interpretar as informações presentes na base da ANTT.

## 📊 Análises realizadas

A partir dos dados, foi possível analisar:

- A quantidade de empresas por estado;
- A distribuição das empresas de acordo com o país de origem;
- A quantidade de empresas que aderiram ao Decreto 1563/95;
- A distribuição dos CEPs por estado.

## 💻 Ferramentas utilizadas

- Microsoft Excel
- Tabelas Dinâmicas
- Gráficos
