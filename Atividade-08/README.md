
# 📊 Atividade 8 – Análise de Dados Ice Cream no Excel

## 📌 Objetivo da Atividade

Desenvolver uma análise de dados no **Microsoft Excel**, utilizando a base de dados **Ice Cream**, com o objetivo de analisar a relação entre a temperatura e a receita obtida com a venda de sorvetes.

A atividade envolveu a organização dos dados em uma **Tabela**, a criação de uma **Tabela Dinâmica**, a elaboração de um **Gráfico de Dispersão** e a aplicação de uma **Linha de Tendência Linear**.

---

### 1. Organização dos Dados

Inicialmente, os dados da base **Ice Cream** foram organizados e formatados em uma tabela no Excel.

A base apresenta duas variáveis principais:

- **Temperature:** temperatura registrada.
- **Revenue:** receita obtida com a venda de sorvetes.

A estruturação dos dados facilitou a análise das informações e a construção das visualizações.

### 2. Criação da Tabela Dinâmica

Foi elaborada uma **Tabela Dinâmica** no Microsoft Excel para organizar e analisar os dados de temperatura e receita.

Essa ferramenta permite explorar as informações de maneira estruturada, facilitando a identificação de padrões e tendências.

### 3. Desenvolvimento do Gráfico

Foi criado um **Gráfico de Dispersão**, permitindo visualizar a relação entre as duas variáveis analisadas.

- **Eixo X:** Temperatura.
- **Eixo Y:** Receita de vendas (R$).

A distribuição dos pontos demonstra uma **relação positiva entre a temperatura e a receita**, indicando que temperaturas mais elevadas tendem a estar associadas a maiores vendas de sorvetes.

### 4. Aplicação da Linha de Tendência

Para complementar a análise, foi adicionada uma **Linha de Tendência Linear** ao gráfico.

A equação apresentada foi:

**y = 20,892x + 50,231**

Essa equação representa a tendência de crescimento da receita conforme o aumento da temperatura.

A linha de tendência facilita a interpretação do comportamento dos dados e permite observar possíveis valores discrepantes.
