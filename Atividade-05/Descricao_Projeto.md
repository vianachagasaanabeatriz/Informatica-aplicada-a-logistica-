# Descrição do Projeto – Empresas Multimodais

O projeto **Empresas Multimodais** foi desenvolvido no Microsoft Power BI com o objetivo de analisar e visualizar informações relacionadas aos operadores e empresas de transporte multimodal.

A utilização do Power BI possibilitou organizar os dados e apresentá-los de maneira visual, utilizando gráficos e recursos interativos para facilitar a interpretação das informações.

## Recursos utilizados

- Importação da base de dados;
- Tratamento e organização dos dados;
- Construção de gráficos;
- Utilização de filtros;
- Desenvolvimento de dashboard interativo;
- Análise visual dos resultados.
