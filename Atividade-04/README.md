# Fundamentação Teórica – Análise de Fecundidade 📊

## 📚 Fecundidade e Análise de Dados

A análise da fecundidade permite observar características relacionadas aos nascimentos e ao comportamento demográfico de uma população ao longo do tempo.

Nesta atividade, foi utilizada uma base de dados de fecundidade do Estado de São Paulo, contendo informações como ano, região, número de nascidos, fecundidade por faixa etária, fecundidade total e idade média das mães.

## 💻 Aplicação

Os dados foram tratados e analisados utilizando o **Microsoft Power BI**, permitindo a criação de gráficos e visualizações para responder às perguntas propostas.

Também foram utilizados filtros por ano e região, possibilitando comparar diferentes períodos e localidades.

## 📈 Visualização dos Dados

Foram utilizados gráficos de linhas, barras, colunas e Treemap para facilitar a interpretação das informações.

A utilização do Power BI permitiu transformar os dados da planilha em informações visuais e interativas, tornando mais simples a identificação de tendências e diferenças entre regiões, anos e faixas etárias.
